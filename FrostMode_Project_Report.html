1. Executive Project Overview

FrostMode is a full-stack gamified Winter Arc daily routine and habit tracking application engineered to help users lock in for a 90-day discipline challenge. The application features a collection of 1,000 structured Winter Arc tasks, strict mode multiplier penalties (+50% bonus / -50% penalty), real-time leaderboards powered by Socket.io, a custom points store, progress heatmaps, and an interactive dark winter glassmorphism user interface.

2 Custom Interactive Ice Cursor & Snow FX

Developed an interactive custom cursor component (CustomCursor.jsx) with dynamic ice trail particles and hover states, combined with an HTML5 canvas snow background (SnowBackground.jsx) for a 60 FPS winter aesthetic.

3 1,000 Winter Arc Tasks & Database Schema Design

Constructed a 1,000-task JSON library (winter_arc_tasks.json) covering Health, Fitness, Mindset, and Productivity. Designed 7 database schemas:

  • users — User profiles, level ranks, wallet points, streaks, avatars
  • arcs — 90-day Winter Arc setup and strict mode parameters
  • days — Daily routine tracking & notes
  • library_tasks — Master repository of 1,000 tasks
  • tasks — User active daily task commitments
  • points_logs — Itemized point earnings and penalty transactions
  • rewards — Custom rewards store redemptions
4 Supabase Cloud PostgreSQL Database Integration
